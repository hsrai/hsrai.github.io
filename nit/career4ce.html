02 / Understand before you automate

Predict. Calculate. Check.

Explore a simply supported beam under a central point load. What happens if the span doubles?

Fixed: b = 250 mm; E = 25 GPa.
Rectangular, uniform, linear-elastic section.

Mmax = PL/4
I = bh³/12
δmax = PL³/(48EI)

20.0Peak moment / kN·m
0.80Midspan deflection / mm
10.0Each reaction / kN

With constant stiffness, deflection varies with the cube of the span.

Teaching model only. Self-weight is excluded; shear deformation, cracking, reinforcement, creep and design-code checks are not represented. This is not an RCC design calculation.

05 / Work like an engineer

Make your work
easy to trust.

  1. Start with a prediction.Sketch the behaviour, estimate the magnitude and name the assumptions before opening the solver.
  2. Keep a traceable calculation.Record units, data sources, formulas, code edition and the clauses actually checked.
  3. Compare with something independent.Use a hand calculation, another method, a measured observation or a benchmark.
  4. Package a clear handover.Include editable files, a short report, a revision log and a two-minute walkthrough. Use GitHub or an organised shared folder.
  5. Learn with people.Ask a faculty member or practitioner for feedback. Collaborate across disciplines and explain decisions in English and the site's working language.
The portfolio test

“Can someone else open it, understand it, check it and build on it?”

Show the problem, the evidence, the result and the limits. A certificate can support your story; a checked project lets others inspect it.
AI as a tutor and reviewerTry: “Here is my solution. Find the first incorrect step, explain why, and ask me a question before giving the answer.” Verify outputs and use authorised data. Local AI also needs hardware, suitable models and the same engineering checks.
